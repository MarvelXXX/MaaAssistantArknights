# ArkPilot

用中文对话分析明日方舟画面，或让模型逐步通过 ADB 操作游戏。每一轮都会读取新的游戏截图，在指令台展示判断理由和执行结果。

## 开始使用

1. 在 Windows 上安装 Node.js 22 或更新版本。打开模拟器或连接已授权 USB 调试的安卓设备，将明日方舟切到前台。
2. 双击同目录的 **start.cmd**。首次启动会安装 npm 依赖并打开 [本机指令台](http://127.0.0.1:17321)。也可以在此目录运行以下命令。

   ~~~sh
   npm ci
   npm start
   ~~~

3. 在设备画面上方选中要操作的 ADB 设备。确认预览对应目标账号。MuMu 有时会为同一实例列出两个 ADB 连接。
4. 打开 **连接设置**，填写 Model URL 和 API Key。接口使用 OpenAI 兼容的 Chat Completions 格式。URL 可以是服务根地址、带路径的 API 前缀或完整的 chat/completions 地址。根地址自动补 v1，本地免鉴权服务可留空 Key。
5. 点击 **获取模型** 或直接填写服务端模型 ID。仅列出一个模型的服务也可在发送时自动识别。有视觉能力的模型选 **截图 + OCR 与模板匹配结果**，纯文本模型选 **仅 OCR 与模板匹配结果**。
6. 在对话框输入指令，回车发送，Shift + Enter 换行。**只读分析**适合查看局面，**允许操作**支持点击、滑动、返回和等待。

可直接尝试这些指令。

- “分析当前画面，告诉我可以进行哪些操作。”
- “打开任务界面，领取可以领取的日常奖励。”
- “这个结算界面显示的是几星？你看到了哪些掉落？”

运行中可以点击 **停止**。已发送到设备的操作可能已经生效。助手提问时，直接在同一设备的对话中补充即可。默认每条指令最多执行 24 步，可在设置中改为 1 至 100 步。

## 图像识别与执行

ArkPilot 是独立的本地程序。它参考 Maa 按画面识别结果选择下一步的设计，从工作区的 Maa 资源目录读取部分模板、阈值及感兴趣区域，通过 OpenCV 匹配任务领奖、邮件、编队开始和结算星级等标志。识别结果带有来源、位置及当帧目标 ID。上游可据此核对资源定义。[Maa 仓库](https://github.com/MaaAssistantArknights/MaaAssistantArknights) · [任务协议](https://docs.maa.plus/zh-cn/protocol/task-schema.html)

Windows OCR 提供屏幕文字与位置。视觉模型还可以直接判断图标和场景。模型结合当前指令、近期对话与已执行步骤，一次返回一个结构化动作。程序将目标 ID 或相对坐标转换为实际设备像素，通过 ADB 输入。输入前会复查前台游戏、画面尺寸与像素变化，输入后重新观察。模型可回答、询问、报告完成或说明为何无法继续。动态场景中的识别质量和响应速度取决于所接模型。

| 能力 | 适用条件 |
| --- | --- |
| Maa 模板 | 默认读取仓库根目录 `resource/` 中选定的国服模板，接近 16∶9 的画面会缩放到 1280×720 进行匹配 |
| Windows OCR | 使用系统已安装的 OCR 语言包，优先选择客户端对应语言。识别状态显示在“识别结果”中 |
| 纯文本模型 | 根据文字和模板目标 ID 点击，也可返回或等待。纯图标和拖动操作需要切换到视觉模型 |
| 游戏客户端 | 支持前台运行的国服官服、B 服、繁中服、日服、韩服和国际服；外服使用 OCR 和模型视觉 |

服务只监听本机回环地址。刷新预览在本机完成。发送指令才会将指令、近期对话和所选识别输入发送给指定模型服务，获取模型列表也会使用填写的 Key。Key 仅在运行内存中使用，刷新页面后需重新填写。非密钥设置保存在当前浏览器。

## 设备与资源路径

程序自动查找 Android SDK、MuMu 的标准安装路径和 PATH 中的 adb。网络模拟器可在连接设置的设备选项中输入 ADB 地址，例如 127.0.0.1:16384，再点击 **连接**。设备离线或未授权时，先检查模拟器的 ADB 开关或安卓设备上的调试授权提示。

可在启动前通过 PowerShell 指定路径和服务端口。

~~~powershell
$env:ARK_ADB = 'D:\Android\platform-tools\adb.exe'
$env:ARK_MAA_RESOURCE = 'D:\MaaAssistantArknights\resource'
$env:ARK_PORT = '17321'
npm start
~~~

若将 ArkPilot 移出仓库，可用 `ARK_MAA_RESOURCE` 指向已有的 Maa 资源目录。找不到模板资源时，程序会显示状态并继续使用可用的识别来源。

## 验证

在此目录运行 `npm test`。测试使用本地模型协议替身和内存设备，覆盖指令到点击再到重新观察、追问、文本输入、坐标映射、只读限制、拒绝过期画面、步数上限与停止任务。
